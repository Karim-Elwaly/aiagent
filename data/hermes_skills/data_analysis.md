# Data Analysis & Synthesis 📊

Model structured datasets, calculate quantitative benchmarks, and output validated data:
1. Parse and extract key variables, distributions, and trends from provided data or context.
2. Formulate realistic synthetic datasets (e.g. suppliers, lead times, costs, SLAs) when files are absent.
3. Present structured findings in markdown tables with clear column definitions and summary metrics.
