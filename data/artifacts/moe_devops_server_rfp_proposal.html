1. Executive Summary

The Ministry of Education (MOE) is advancing a critical digital transformation initiative to modernize software development, automated testing, security compliance, and continuous delivery across national-scale educational platforms. Our turnkey solution establishes an enterprise-grade, on-premises deployment of the DevOps Server Platform at the Roxy Data Center, providing:

  • Distributed Source Code Management (SCM) with granular RBAC, branch protection policies, and tamper-evident audit logging.
  • Declarative CI/CD Pipelines with auto-scaling distributed runners, dependency caching, and parallel execution.
  • Enterprise Agile Work Tracking featuring integrated Scrum and Kanban boards mapped to MOE educational portfolios.
  • Universal Artifact Registry supporting OCI container images, Maven, npm, PyPI, and Helm with local proxy caching.
  • Continuous DevSecOps Security automating SAST, DAST, SCA dependency scanning, and pre-commit secret detection.
  • 100% Sovereign Data Residency operating completely within the Roxy Data Center with zero outbound hyperscaler telemetry.

2. Project Scope & Architecture Overview

The solution is deployed across high-availability (HA) clustered nodes within the Roxy Data Center:

  • Perimeter & Identity: Redundant reverse proxies (F5 / NGINX Plus) integrated natively with MOE Active Directory / OpenLDAP via SAML 2.0 and Kerberos.
  • Control Plane: Clustered stateless application nodes backed by an active-passive PostgreSQL cluster managed by Patroni with WAL-G archiving.
  • Execution Fabric: Distributed containerized runner pools segmented into static analysis, security inspection, and production deployment tiers.
  • Persistent Storage: Enterprise SAN/NAS integration (NFSv4 / NVMe-oF) with automated local snapshot replication.
