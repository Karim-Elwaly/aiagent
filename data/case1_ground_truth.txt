# FORENSIC BENCHMARK REPORT: CASE 1
## Case Name: APT Enterprise Intrusion & Lateral Movement
**Complexity Level:** High  
**Evaluated Environment:** Enterprise On-Premises Windows Active Directory Infrastructure  
**Target Domain:** `corp.contoso.com`  
**Primary Compromised Host:** `WKSTN-FIN-04.corp.contoso.com` (`10.20.10.45`)  
**Secondary Compromised Host (DC):** `DC01.corp.contoso.com` (`10.20.10.10`)  
**Threat Actor Infrastructure:** `185.220.101.45` (C2 / Staging), `203.0.113.119` (Phishing Mailer), `198.51.100.240` (Exfiltration Drop)

---

### 1. Executive Summary

Case 1 replicates an advanced persistent threat (APT) multi-stage intrusion emulating techniques associated with sophisticated threat actors (e.g., APT29 / UNC2452). The adversary gains initial foothold through targeted spear-phishing delivering a macro-laced document (`Invoice_90214.docm`). Upon document execution, an obfuscated Base64-encoded PowerShell cradle spawns directly from Microsoft Word to download second-stage payloads via a native Living-off-the-Land Binary (`certutil.exe`). 

Post-exploitation includes in-memory credential harvesting from the Local Security Authority Subsystem Service (`lsass.exe`) using Mimikatz, yielding cleartext Domain Administrator credentials (`da_admin`). Armed with privileged credentials, the actor executes lateral movement across the internal subnet via SMB/RPC, instantiates a remote service (`PSEXESVC`) on the primary Domain Controller (`DC01`), and creates a stealthy persistent backdoor user (`svc_backup_admin`) provisioned into the Builtin `Administrators` group. Simultaneously, the compromised endpoint establishes high-frequency (60-second jitterless) command-and-control (C2) beaconing over non-standard TLS/SSL on port 8443, culminating in high-speed bulk exfiltration of proprietary financial archives (450 MB) to an untrusted external server.

This benchmark dataset evaluates the ability of SIEM, XDR, and automated incident correlation engines to reconstruct the multi-system timeline across disjointed log formats (Email Gateway, Windows Security EVTX, Sysmon Operational, and Palo Alto Firewall CSV) while strictly distinguishing adversarial activity from co-mingled benign enterprise operations and high-volume noise.

### 5. Benign / False Positive Traps

The raw logs contain background operational activities designed to evaluate detector specificity. Automated evaluation tools **MUST NOT** classify these events as true intrusion incidents:

1. **Trap 1: Benign Marketing Email Quarantine (Email Gateway)**
   - *Log entry:* `MID 7401180` from `offers@enterprise-deals-weekly.biz` (Score: 78).
   - *Why it's benign:* Routine bulk advertising caught by the standard anti-spam filter. Contains no active exploit, macro, or weaponized payload.
   - *Failure condition:* Alerting on this as a targeted APT intrusion or initial access incident.

2. **Trap 2: Routine Sysmon & Windows System Activity (Endpoint Logs)**
   - *Log entry:* Sysmon Event 1 for `svchost.exe -k netsvcs -p -s Schedule` (PID 1148) and `gpupdate.exe /target:computer` (PID 0x18ac).
   - *Why it's benign:* Native Windows group policy refreshes and Task Scheduler host instances running under `NT AUTHORITY\SYSTEM`.
   - *Failure condition:* Flagging legitimate operating system parent-child execution branches as LOLBins or unauthorized process creation.

3. **Trap 3: Enterprise OneDrive Cloud Synchronization (Firewall Log)**
   - *Log entry:* Flow from `10.20.10.62` to `13.107.136.9:443` (Microsoft Azure IP range) transmitting 385 MB over 360 seconds under App-ID `ms-onedrive`.
   - *Why it's benign:* Legitimate corporate file backup to authenticated tenant cloud storage by employee `mjones`.
   - *Failure condition:* Classifying high-bandwidth corporate Microsoft 365 traffic as data exfiltration.

#### 6.2 Correlation Graph Requirements
The automated correlation engine must produce a unified Directed Acyclic Graph (DAG) linking:
1. `Invoice_90214.docm` (Email Gateway) $\rightarrow$ `WINWORD.EXE` $\rightarrow$ `powershell.exe` download cradle (Sysmon Event 1).
2. `powershell.exe` $\rightarrow$ `certutil.exe` retrieving `stage2.dll` from `185.220.101.45` (Windows Event 4688 + Firewall Log).
3. `mimikatz.exe` memory access on `lsass.exe` (Sysmon Event 10) $\rightarrow$ Token elevation via `runas.exe` to `da_admin` (Windows Event 4648).
4. `da_admin` session on `WKSTN-FIN-04` $\rightarrow$ Network logon Event 4624 (Type 3) to `DC01` $\rightarrow$ PsExec service creation (Event 7045).
5. Lateral execution session $\rightarrow$ User creation `svc_backup_admin` (Event 4720) + Group membership addition (Event 4732).
6. Endpoint process context $\rightarrow$ Outbound firewall beaconing (`185.220.101.45:8443`) and SSL exfiltration (`198.51.100.240:443`).
